# cardano-drep-documentation

Talos writes vote rationales and vote context in first person: "I vote", "my earlier votes", and "what I verified". Keep source quotations verbatim and preserve the vote, evidence, references, and AI authorship disclosure.

After editing a rationale, publish its exact bytes at a commit-pinned URL and update its content hash in the vote context. After editing the vote context, refresh the unsigned transaction anchor URL and hash. Never sign a transaction whose anchor refers to a superseded rationale.
